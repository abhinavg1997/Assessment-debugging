## Programmer Assessment Q4

This programs uses uv, a Python package manager for project dependency management.

1. To install uv:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
2. Restart your terminal or run command2. Restart your terminal or run command (Below is for Bash based execution)

```bash
source ~/.bashrc
```

3. Setup virtual Environment and install dependencies


```bash
uv sync
```
4. Run the app


```bash
uv run main.py
```

5. Access the App on your browser at:

```
http://127.0.0.1:100300
```

or 


```
http://localhost:100300
```
